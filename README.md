# Telegram聊天记录通用美化工具

## 概述

本项目提供了一套通用的 CSS 和 JavaScript 文件，用于美化和增强 Telegram 导出的聊天记录 HTML 文件。无需修改原始 HTML，只需替换 CSS/JS 引用即可获得现代化的阅读体验。

**✨ 核心优势**：原版 Telegram 导出的 HTML 文件**一个字都不用改**，只需引用本项目的 CSS 和 JS 文件即可自动美化。

## 文件说明

| 文件 | 说明 |
|------|------|
| `css/style.css` | 全部美化样式（现代化UI、动画、响应式布局、PC/移动端适配），每个代码块均有清晰的中文注释 |
| `js/script.js` | 全部交互功能（灯箱、导航、预览、缩放、移动端触摸手势等） |

## 使用方法

1. 将 `css/style.css` 和 `js/script.js` 放到 Telegram 导出目录中
2. 确保 HTML 文件中引用了这两个文件（Telegram 导出的 HTML 默认就有这两行引用）：

```html
<link href="css/style.css" rel="stylesheet"/>
<script src="js/script.js" type="text/javascript"></script>
```

3. 打开 HTML 文件即可看到美化效果

**文件结构示例**：
```
your-chat-export/
├── messages.html        （Telegram导出的HTML）
├── css/
│   └── style.css       （美化样式）
├── js/
│   └── script.js       （交互脚本）
└── photos/videos/...   （Telegram导出的媒体文件）
```

## 功能特性

### 媒体灯箱查看器

- **自动创建**：灯箱容器由 JS 自动生成，无需手动添加 HTML
- **图片/视频混合浏览**：按 DOM 顺序混合排列，支持上下切换
- **媒体筛选**：左上角筛选按钮，根据当前媒体类型动态显示「全部」和「图片/视频」选项，切换媒体时自动更新
- **PC端打开动画**：从缩略图位置展开到灯箱居中（类似 iOS 打开 APP 动画），背景毛玻璃同步淡入
- **关闭动画**：媒体淡出 + 微缩，所有控件同步淡出（无残留），背景同步淡出，流畅无卡顿
- **图片缩放**：点击图片切换 1x/2x 缩放（展开动画中放大不会被回调覆盖），滚轮精细缩放（0.5x ~ 5x）
- **拖拽移动**：放大后鼠标按下即可拖拽，实时跟手无延迟
- **视频快进快退**：鼠标悬停视频时，方向键短按跳转、长按连续快进/快退，速度随按住时长自动加速
- **键盘快捷键**：
  - `←` / `→`：切换上/下一个媒体（视频悬停时为快退/快进）
  - `空格`：暂停/播放视频
  - `1` / `2` / `5` / `0`：设置快进快退步长（1/2/5/10秒）
  - `Esc`：关闭灯箱
- **移动端触摸手势**：
  - 双击图片放大到 2x（带 0.2s 平滑缩放动画，双 rAF + 强制重排确保动画始终可见），任意放大状态双击缩小回 1x
  - 双指捨合缩放（pinch-to-zoom），以双指中心为缩放原点，松手接近 1x 时平滑回弹
  - 放大后单指拖拽平移图片，放大状态点击图片外区域关闭灯箱
  - 左右滑动切换媒体，跟手滑动动画，滑动过程中实时显示下一个/上一个媒体预览图
  - 滑动过程中优先显示已缓存的原图，否则显示缩略图预览，滑动中不显示 loading 转圈（避免位置异常影响观感）
  - 滑动切换无闪烁（等新图片 decode 完成后再移除旧预览，500ms 超时保护防止页面卡死）
  - 切换动画期间禁止关闭灯箱和新触摸操作（touchstart/move/end 全链路锁定）
  - 只有点击媒体画面外的背景遮罩才关闭灯箱（触摸坐标判断，点击视频预览图不会关闭）
  - 默认状态显示筛选栏和关闭按钮，放大状态自动隐藏所有UI
  - 按钮与媒体触摸事件完全隔离，不会误触缩放
  - 视频灯箱：有缓存尺寸时 wrapper 精确匹配视频比例，预览图用 cover 填满无空隙；无缓存尺寸时只显示播放按钮 loading
  - 视频 wrapper 带圆角和阴影，与图片视觉一致，播放后切换为 contain 保持原始比例
  - 视频全屏：点击播放后将 video 元素从 wrapper 中移出直接放入 content，去除所有容器约束，object-fit:contain 保持完整比例不裁切，彻底消除白条/画面跳动问题
  - 全屏状态与网页操作完全隔离（不会退出全屏关闭灯箱）
  - 入场动画：背景遮罩立即淡入，内容等图片 decode 完成（最多 300ms）后缩放淡入；入场动画期间禁止 loading 出现，动画结束后才允许
  - 移动端用 html overflow:hidden 锁定滚动（不修改 body 的 position，避免触发 GPU 纹理释放导致页面图片白屏闪烁）
  - 灯箱打开 500ms 内不响应单击关闭和双击缩放，防止移动端双击误触导致灯箱立即关闭
- **网络异常兜底**：
  - 图片：先显示缩略图预览 + 后台加载原图，原图就绪后无缝替换；全部失败时从 DOM 移除空白容器，只显示 loading
  - 视频：poster 失败时只显示播放按钮 loading（不与图片 loading 重叠），video 元素无白边框
  - 网络异常时灯箱背景遮罩始终立即显示，不会出现空白页面
  - 视频 poster 自动从 DOM 已显示缩略图获取，网络断开也能显示预览图
- **加载状态优化**：
  - 点击媒体卡片立即进入灯箱，不阻塞等待任何异步加载
  - 原图缓存检测：打开灯箱和滑动切换时优先检查原图是否已在浏览器缓存中，已缓存则直接显示原图，不显示缩略图和 loading
  - 图片加载策略：原图已缓存直接显示；有缩略图时先展示缩略图，300ms 后原图仍未加载才显示 loading；无缩略图时 300ms 后显示 loading
  - 入场动画期间（约 500ms）禁止 loading 出现，彻底消除打开灯箱时先闪转圈再显示画面的问题
  - 关闭灯箱时 loading 动画与媒体同步淡出，不会残留
  - 视频未 canplay 时播放按钮外圈转圈加载（▶ 不旋转），就绪后自动切换为正常样式
  - 视频无缓存尺寸时 wrapper 背景透明，不显示多余的背景框

### 日期导航

- 右下角日历图标打开日期导航面板
- 按年份分组，支持折叠/展开
- 打开时自动定位到当前可见日期
- 年份折叠/展开动画流畅自然：基于实际内容高度计算过渡（而非固定值），展开 0.4s、折叠 0.3s，无卡顿
- 点击日期快速跳转，带精致的边框光晕脉冲定位动画（1.4s，两次闪烁，不透明浅蓝紫背景色）
- 定位动画包含：日期框边框光晕 + 左右水平装饰线脉冲 + 两端旋转发光菱形钻石光点装饰
- 定位动画结束后背景自然回到默认白色（无 forwards，最后一帧已是白色）
- 快速重复定位时自动清除旧动画并重新播放，确保完整的两次脉冲
- PC端：悬停日期卡片显示该日期的第一张图片预览浮层
- 移动端：日期卡片内直接内嵌缩略图，无需悬停即可查看

### 标签导航

- 右下角话题图标打开标签导航面板
- 自动收集所有消息中的 `#标签`
- 按消息数量排序，显示每个标签的消息计数
- 点击标签进入二级面板查看消息列表（消息卡片依次淡入上移加载动画）
- 打开面板和返回一级面板时标签气泡按行批量淡入上移（双 rAF + offsetTop 分组同一行，每行间隔 50ms，自然灵动不冗长）
- 返回一级面板时二级面板缩放淡出，一级标签气泡依次淡入上移，动画自然灵动
- 点击消息直接跳转到原位置并高亮（1.2s 边框脉冲动画）
- 消息中的 `#标签` 可直接点击打开对应标签面板

### Open Graph 链接预览

- 自动检测消息中的外部链接（排除 Telegram 链接）
- 通过 CORS 代理获取 Open Graph 元数据
- 显示链接标题、描述和预览图
- 悬停预览卡片有上浮阴影动画

### 分页链接美化

- 自动检测 Telegram 导出的 Previous/Next messages 分页链接
- 英文文本替换为中文（「查看更早的消息」/「查看更多消息」）
- 彻底去除所有状态的下划线和 border-bottom（覆盖 a 标签所有伪类及全局链接样式）
- PC端：精美渐变卡片设计，左侧蓝紫渐变色彩条作为箭头区域（悬停时自动展宽），右侧文字区展示主标题 + 目标文件名副标题，悬停卡片上浮 + 光晕阴影 + 箭头方向移动
- 移动端：简洁毛玻璃卡片，点击时有弹性缩放 + ripple 水波纹从触摸点扩散的动效，无悬停动画干扰

### 网页标题与图标

- 自动从页面 header 提取聊天对象名称，替换默认的「Exported Data」标题
- 自动添加 Telegram 风格的 SVG favicon（蓝色渐变圆形 + 白色纸飞机）

- **消息卡片**：圆角卡片设计，悬停上浮 + 柔和渐变背景 + 多层阴影 + 顶部装饰线
- **日期分隔符**：胶囊形日期标签，悬停变色上浮 + 两侧渐变装饰线延伸
- **头部装饰**：渐变流动条 + 背景斜线交叉图案 + 菱形浮动装饰 + 光效呼吸动画

- **代码规范**：CSS 文件中每个 `{}` 代码块均有清晰的中文注释

### 移动端适配

- **媒体布局**：隐藏头像列，内容占满宽度，一行 3 列网格，预览图更大
- **灯箱防白屏**：用 `html overflow:hidden` 锁定滚动，彻底不触发 GPU 纹理释放，从根本上解决 Via 等浏览器打开灯箱时页面媒体卡片白屏闪烁问题
- **防误触**：灯箱打开 500ms 保护期，防止双击打开后立即关闭或误触放大
- **灯箱动画**：双击放大 2x / 双击缩小 1x（均带 0.2s 平滑动画，双 rAF + 强制重排确保动画不丢失），双指缩放，单指拖拽
- **灯箱视频**：wrapper 精确匹配视频比例，预览图 cover 填满无空隙；点击播放后 video 元素从 wrapper 移出独立显示，object-fit:contain 保持完整比例，全屏时无任何容器约束
- **灯箱关闭**：只有点击媒体画面外的背景遮罩才关闭（触摸坐标判断），视频全屏时不会关闭
- **灯箱滑动切换**：优先显示已缓存原图，否则显示缩略图，滑动中不显示 loading，500ms 超时保护
- **网络异常兜底**：图片先显示缩略图再显示 loading，全部失败从 DOM 移除空白容器；视频 loading 不重叠，poster 从 DOM 获取
- **灯箱UI状态**：默认显示筛选栏和关闭按钮，放大状态自动隐藏所有控件，切换按钮隐藏（用滑动替代）
- **灯箱关闭动画**：所有控件与媒体同步淡出，无按钮残留卡顿
- **按钮隔离**：触摸事件与按钮点击完全隔离，不会误触缩放功能
- **日期分隔符**：缩小间距、内边距、字体和圆角，减少空间占用
- **日期导航面板**：日期卡片毛玻璃背景持续可见（面板背景更透明），内嵌缩略图，年份标题紧凑缩小，定位动画不透明浅蓝紫背景
- **链接预览**：纵向布局，预览图占满宽度显示在顶部
- **标签导航面板**：毛玻璃背景，标题/按钮/标签/消息卡片全面缩小，弹窗高度避免与底部按钮重叠，二级面板标题完全不透明防止一级标题透出，标签名称居中显示
- **标签导航滚动条**：一级/二级面板滚动条均为透明背景 + 半透明蓝紫滑块，与毛玻璃风格协调
- **滚动隔离**：日期导航和标签导航面板均做滚动隔离（`overscroll-behavior: contain`），不会穿透到背景页面
- **触摸体验**：去除点击蓝色高亮方块，禁用悬停动画
- **加载策略**：原图已缓存直接显示；有缩略图则先展示缩略图，300ms 后才显示 loading；入场动画期间禁止 loading 出现，关闭灯箱时 loading 同步淡出
- **滚动按钮**：毛玻璃透明背景，点击时保持透明不变为不透明白色（`!important` 覆盖系统高亮），弹性缩放动效
- **性能优化**：禁用消息滑入动画，灯箱 `touch-action: none` 防止浏览器默认手势干扰，字体抗锯齿渲染，尺寸计算复用 `calcMediaDisplaySize`
- **转发消息**：引用竖线改为低存在感的细灰色渐变线

### 图标设计

- 所有图标均使用统一设计的 SVG 矢量图标，线条粗细匹配场景，与页面风格和谐
- 灯箱按钮：SVG 图标由 CSS 控制尺寸（按钮宽高的50%），在不同尺寸按钮中自动缩放
- 分页箭头：嵌入左侧渐变色彩条中，白色 chevron，垂直居中无偏移
- 标签导航返回按钮：左箭头图标（18px，与关闭按钮协调），与切换按钮视觉区分
- 标签导航关闭按钮：精致圆角 X 图标，18px CSS 控制尺寸

### 滚动按钮

- 一键滚动至页面顶部或底部，平滑滚动动画
- 根据滚动位置自动显隐：已在顶部时隐藏顶部按钮，已在底部时隐藏底部按钮
- PC端：右侧贴边竖排 pill 形状按钮（right: 6px，不覆盖内容区），毛玻璃背景 + 图标 + 文字标签，悬停左移 + 光晕阴影
- 移动端：右侧垂直居中圆形按钮，透明毛玻璃背景（`backdrop-filter: blur(16px)`），点击保持透明（不变白色），弹性缩放动效

### 页面加载优化

- Telegram 风格加载遮罩：蓝色渐变圆形纸飞机图标（悬浮动画）+ 蓝紫渐变进度条 + "加载中"提示文字
- **三条件并行等待**：至少显示 1 秒 + 等待所有预览图加载完成 + 等待所有媒体尺寸缓存完成，全部满足后才淡出遮罩
- **8 秒超时保护**：超时后提示「加载超时，部分内容可能未完全加载」，再等 1 秒强制关闭遮罩
- 初始化完成后先让页面内容渲染就绪（用户看不到，遮罩盖住），再 0.5s 平滑淡出遮罩
- 遮罩淡出后自动移除 DOM，不留残余元素

### 自动化处理

脚本在页面加载时自动执行以下操作：

1. 创建灯箱容器（含移动端触摸手势支持）
2. 添加头部背景装饰
3. 转换日期格式（26 October 2023 → 2023-10-26）
4. 合并连续消息（joined 消息合并到主消息）
5. 收集所有媒体并绑定点击事件
6. 创建日期导航面板
7. 创建标签导航面板
8. 初始化 Open Graph 链接预览
9. 美化分页链接（英文 → 中文 + 现代化卡片样式）
10. 替换网页标题（Exported Data → 聊天对象名称）
11. 添加 Telegram SVG favicon
12. 创建滚动至顶部/底部按钮（滚动位置自动显隐）
13. 淡出加载遮罩（最低 1 秒显示，先渲染页面内容再淡出遮罩，避免用户看到样式变化）

## 注意事项

1. **文件路径**：确保 `css/style.css` 和 `js/script.js` 的路径与 HTML 中的引用一致
2. **视频播放**：需要浏览器支持 HTML5 视频格式
3. **链接预览**：依赖 CORS 代理服务，需要网络连接，部分链接可能无法获取预览
4. **性能**：消息量极大时（数千条以上），初始化可能需要几秒钟
5. **移动端**：建议使用竖屏浏览以获得最佳体验
